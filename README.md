# 🎬 ANN Movie Recommendation System

## Overview

The ANN Movie Recommendation System is a Deep Learning project designed to recommend movies based on user preferences and historical movie ratings.

The system uses an Artificial Neural Network (ANN) with user and movie embedding layers to learn relationships between users and movies. It predicts ratings for unseen movies and recommends the Top 10 movies to each user.

## Objectives

- Build a movie recommendation engine using ANN.
- Understand embedding layers in Deep Learning.
- Predict user ratings for unseen movies.
- Generate personalized movie recommendations.
- Evaluate model performance using MAE and RMSE.

## Dataset

**MovieLens Latest Small Dataset**

Contains movie information, user IDs, movie IDs and ratings.

## Model Architecture

User Input + Movie Input → Embedding Layers → Flatten → Concatenation → Dense Layers → Rating Prediction → Top-10 Recommendations.

## How to Run

1. Clone this repository.
2. Open `ANN_Movie_Recommendation.ipynb` in Google Colab.
3. Run the notebook cells sequentially.
4. Train the ANN model.
5. Enter a user ID to generate movie recommendations.
